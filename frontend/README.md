# Fantasy — браузерный клиент (Strange Lands)

Стек: **TypeScript**, **React 18**, **Vite 5**.

UI в духе Fantasy Empires: **лобби** (миры и игроки) и **партия** (карта-провинции + боковая панель + Мастер подземелий).

## Запуск

1. Поднять бэкенд (порт **8080**) из корня репозитория:

   ```bash
   ./gradlew bootRun
   ```

2. В этой папке:

   ```bash
   npm install
   npm run dev
   ```

3. Открыть Vite URL (обычно `http://localhost:5173`). Запросы `/api/*` проксируются на Spring.

Сборка статики: `npm run build` → каталог `dist`.

## Экраны

| Экран | Назначение |
|--------|------------|
| **Лобби** | Создать игроков и мир, поселить правителя, нажать «В партию» |
| **Партия** | Карта почти на весь экран, справа панель хода / DM / провинции; стройка, найм, перемещение, завершение хода |

Правый клик по провинции — быстрое меню. Левый — выбор для панели.
