# Fantasy — браузерный клиент

Стек: **TypeScript**, **React 18**, **Vite 5**.

## Зачем так

| Выбор | Зачем |
|--------|--------|
| **TypeScript** | Типы для ответов REST и состояния UI, меньше ошибок при росте экранов. |
| **React** | Большая экосистема, удобно собирать карту, панели, формы. |
| **Vite** | Быстрый dev-сервер и сборка; уже настроен **proxy** ` /api` → `http://localhost:8080`. |

Альтернатива близкая по смыслу: **Vue 3 + Vite + TypeScript**, если предпочтительнее однофайловые компоненты без JSX.

## Запуск

1. Поднять бэкенд (порт **8080**), например из корня модуля `fantasy`:

   ```bash
   ./gradlew bootRun
   ```

2. В этой папке:

   ```bash
   npm install
   npm run dev
   ```

3. Открыть в браузере указанный Vite URL (обычно `http://localhost:5173`). Запросы к `/api/*` уйдут на Spring.

Сборка статики для выдачи из Spring при необходимости: `npm run build` → каталог `dist`.
