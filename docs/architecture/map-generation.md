# Генерация карты провинций

Детерминированный визуальный рельеф поверх неизменной игровой сетки провинций.
Источник тайлов: [Kenney Map Pack](https://kenney.nl/assets/map-pack) (CC0).

## Инварианты

1. **Детерминизм.** Один и тот же `worldId` (+ размеры мира) всегда даёт одинаковый рельеф и декор.
2. **Две сетки.**
   - Игровая: `rows × cols` провинций (`LandDto`), клики / fog / tooltip / здания.
   - Визуальная: `rows*3 × cols*3` подтайлов рельефа (и декора).
3. **Области одного tone** — цельное плато с единым fill внутри.
4. **Соседние клетки** (по стороне) отличаются по высоте максимум на `|Δtone| ≤ 1`.
5. **Вода** только во внешней рамке острова (`frame_*` + `water_*`). Внутри карты воды нет.
6. **Края возвышенности:**
   - юг (S) — 3D-cliff;
   - север / запад / восток (N/W/E) — плоская волна;
   - каждая граница завершается прямым краем, внешним или внутренним углом из набора Kenney.
7. **Запрещены:** одиночные подтайлы, полосы шириной 1, чрезмерно вытянутые области, неподдерживаемые маски стыков (нормализуем поле, а не рисуем fallback).
8. **Декор** (деревья, грибы, отдельно стоящая гора) — только на внутренних fill-подтайлах; не на краях, cliff, зданиях и UI-маркерах; не влияет на клики/tooltip.
9. **Плотность декора** (от подходящих внутренних подтайлов, ориентир по референсу Kenney):
   - деревья: 10–15%;
   - грибы: 2–3%;
   - одиночная гора/скала: 1–2%.

## Биомы по tone

| tone | biome   | визуальный kit |
|------|---------|----------------|
| ≤ 4  | swamp   | dirt           |
| ≤ 7  | plains  | grass          |
| ≤ 9  | forest  | grass + деревья|
| ≥ 10 | hills   | stone          |

## Слои отрисовки (`ProvinceMap`)

1. Фон воды + внешняя рамка острова.
2. Сетка terrain-подтайлов (без pointer-events).
3. Слой декора (без pointer-events).
4. Прозрачные кнопки провинций (`1×1`) поверх.

## Качество / валидация

Валидатор раскладки проверяет: детерминизм, отсутствие внутренней воды, `|Δtone| ≤ 1`, отсутствие одиночек/тонких полос, отсутствие неподдерживаемых масок, декор только на fill, плотности в заданных диапазонах.
