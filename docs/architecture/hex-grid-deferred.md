## Вердикт (кратко)

Переход реализуем: домен уже графовый (`Land.neighboring`), основная стоимость — **UI + Kenney-автотайлы**, не move/fog.

| Слой | Сложность |
|------|-----------|
| Соседи в `WorldFactory` (6 вместо 4) | Низкая |
| Move / fog / панель (граф) | Почти без изменений |
| FE layout гексов (клики, pan, fog clip) | Высокая |
| Terrain Kenney NESW → hex | Очень высокая (новый арт) |

Компромисс без UI-перестройки (обсуждался, не выбран как hex): **8-соседи на квадрате** (диагонали) — только фабрика соседей.

## Рекомендуемые фазы при возврате

1. Topology-only: hex-соседи в `WorldFactory` + тесты + assert смежности в `moveWarriors`.
2. Hex layout FE (раскладка, hit hex, fog); terrain временно упростить.
3. Hex terrain (новый tile set) или сознательный минимализм.
4. Полировка рамки/тултипов.

Default layout при возврате: **pointy-top, odd-r**; `sizeX×sizeY` = колонки×ряды гексов.

## Когда не начинать

Пока приоритет — контент, правила найма и экономика: текущий квадрат + Kenney достаточен.
